Sources and interpretation

Coverage varies by investigation. Each release draws on different providers, records and years. A higher count in one release does not measure growth in offshore activity. A record can link to several countries.

Corporate roles have dates and directions. A shareholder, an intermediary and a registered agent describe different relationships. Blank relationship dates leave the period unknown. A listed name alone does not show ownership today.

OECD reviews answer a different question. Read the review year and status alongside the rating. The assessment year can differ from the ICIJ source window.

Using the atlas. Your filters run in your browser against the published files. Following a source link opens that publisher’s website.

When updates run. The atlas is scheduled to check its sources on the third of each month at 11:23 UTC. See the last successful checks.
